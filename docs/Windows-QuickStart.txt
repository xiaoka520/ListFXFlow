ListFXFlow 0.2.3 build 43 · Windows x64

本构建为 0.2.3 build 43，未发布期间只增加构建号。关闭或最小化窗口后常驻系统托盘。滚轮固定使用精细增量，不额外生成动画；Windows 系统输入注入已拆到独立线程。真实双端滚动和移动手感仍需测试。
Mac 端不再为 Caps 切换输入源；中文混输和候选保留需要连续输入验证，测试途中不要点击其他窗口。

1. 运行 ListFXFlow-Setup-x64-0.2.3-b43.exe，按向导安装到当前用户，无需另装 .NET。安装器和应用均会请求管理员授权，以便控制管理员窗口。
   也可解压 ListFXFlow-Windows-x64-0.2.3-b43.zip，直接运行 ListFXFlow.exe。
2. 用雷雳线直连 Mac，确认 Windows 出现 Thunderbolt / USB4 网络适配器。
3. Mac 打开 ListFXFlow.app 后自动启用共享；若缺少权限，在向导中分别授权。Mac 应用常驻菜单栏。
4. Windows 选择雷雳有线网卡，点击“连接 Mac”，不需要配对码。优先尝试保存的 Mac IP；留空时优先使用上次成功连接的地址，不可用再自动发现。手动 IP、网卡及成功连接地址会保存，已连接时不主动切换地址。
5. 拖动 Windows 屏幕到 Mac 的左、右、上、下并调整错位；界面不再显示“Windows 位于 Mac 某侧”的提示文字。

本机触控板手势屏蔽：
- 新增默认关闭的 Windows → Mac 多指滑动试验，须两端分别开启；Mac → Windows 多指手势转发仍未开放。
- 指针控制 Mac 时自动屏蔽 Windows 本机触控板多指手势，与旧实验开关及 Mac 端设置无关；返回 Windows、断线、停止或锁屏后恢复本机处理。
- 单指移动、点击、普通鼠标移动和实体鼠标滚轮继续使用原通道。
- 双指不注册原始触点接管，交给 Windows 默认处理；通过现有原始滚轮路径转发至 Mac，Windows 本机不滚动；三指及以上系统手势继续消费，只有双方开启试验才读取并转发触点。没有注册 Mac 虚拟触控板，此试验不使用虚拟 HID 权限。
- 界面“本机触控板”显示屏蔽状态。如果 Windows 拒绝接管，会显示原因；可点击“重试”或返回本机后重新跨屏。
- 原生接管需要当前 Windows 构建提供相应 API。每次跨屏通过主进程向指定工作进程重新申请前台，并在确认后才报告成功。实际设备兼容性需要在笔记本验收。
- 普通键鼠和网络不等待手势初始化；工作进程无响应或崩溃时回收它，普通共享继续。
- 日志位于 %LOCALAPPDATA%\ListFXFlow\Diagnostics\touchpad-main.log 与 touchpad-worker.log，不记录输入内容。
- 双指滚动诊断另见同目录 touchpad-scroll-main.log 和 touchpad-scroll-worker.log；仅汇总各环节事件次数，后台写入，不记录键入内容。

运行方式：
- 关闭主窗口或最小化窗口后，程序留在系统托盘；双击托盘图标重新打开主界面。
- 托盘右键菜单可以打开主界面、开始/停止共享或退出。
- 只有“退出 ListFXFlow”会结束程序；关闭窗口不会断开共享。
- 滚轮固定使用精细增量，无需开关；不额外生成动画，由目标应用处理滚动。
- Windows 安装包未做 Authenticode 签名，首次运行可能被 SmartScreen 拦截；请选择“更多信息”后继续。

鼠标在哪台设备，键盘就输入到哪台设备。键盘和鼠标可以各自连接在任一端。
Caps Lock 会同步切换两端的开启状态和指示灯。
Ctrl + Alt + Esc 随时停止共享。断线、休眠后共享停止；未安装登录组件时，锁屏也会停止共享。
本版支持每台设备的主显示器，不传画面。
复制文字、文件或文件夹后自动同步；大文件请等显示“文件已同步 · 可在远端粘贴”再粘贴。Windows 使用 Ctrl+V，Mac 使用 Command+V。多选、子目录和空目录均可同步。复制新内容会取消旧任务，停止共享会中止未完成传输。
Windows 登录前共享已移除；登录页、锁屏不提供共享输入。UAC 安全桌面期间暂停输入但保留连接，需在 Windows 本机确认或取消，返回普通桌面后自动恢复；暂停前排队的输入不会补发。若安装过旧版系统组件，安装器或应用会清理旧组件，不再创建服务。

未找到 Mac 时：
- Mac 是否已经启用共享？
- 是否使用真正支持数据的雷雳线？
- 是否选中了雷雳网卡，而不是普通 Ethernet 网卡？
- Windows 雷雳 / USB4 驱动是否已建立网络接口？
- 两端 IPv4 地址是否处于可互通子网？
- 防火墙是否允许该应用的 UDP 49235、TCP 49234 和剪贴板 TCP 49236 通信？

程序不会修改网络配置或防火墙。
这是尚未完成双端真机验收的开发预览包，未做发行证书签名。

Windows 游戏保护（双端 build 41）：
- 控制 Windows 后，Ctrl + Alt + L 锁定/解除 Windows；Mac 键盘对应 Ctrl + Option + L。主界面及托盘也可操作。锁定期间暂停跨屏，普通键鼠不被接管到 Mac。
- 自动保护默认打开，可在 Windows 主界面关闭。依据“隐藏指针 + 全屏或受限区域”识别，属于启发式；全屏视频等也可能触发。解除自动锁定后，同一次捕获状态不会立即重新锁住。
- 插在 Mac 的鼠标在锁定期间改发相对位移；解锁按 Windows 当前指针重新同步。游戏是否接受软件相对输入仍需实测。
- Ctrl + Alt + Esc 随时停止共享；断线、停止和锁屏清除游戏锁定，不会下次连接后继续锁住。

多指手势试验（需要两端 build 41）
默认关闭。Windows 勾选“向 Mac 转发多指手势（实验）”，Mac 开启“接收 Windows 多指手势（实验）”。指针移到 Mac 后尝试三指 / 四指滑动。双指滚动独立工作；关闭试验仍会屏蔽 Windows 本机多指手势。显示已提交事件仅表示已调用 Mac API，实际系统响应需实机确认。

原始触点诊断（build 42 开发试验）：
在 PowerShell 中运行：
& "$env:LOCALAPPDATA\Programs\ListFXFlow\ListFXFlow.exe" --touchpad-hid-diagnostics
诊断文件：%LOCALAPPDATA%\ListFXFlow\Diagnostics\touchpad-hid.json
此命令只收集触控板类型和硬件 ID，不安装驱动，不记录坐标或输入内容。
普通安装包不含已签名 PTP 驱动；没有单独加载观察驱动时仍使用 SDK。
